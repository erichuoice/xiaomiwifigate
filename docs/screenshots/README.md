# 截图

README 顶部「截图」用的三张图，均来自真实运行页面（学生姓名、设备 MAC、内网 IP 已遮挡）：

| 文件 | 对应界面 | 尺寸 |
|---|---|---|
| `answer-page.png` | 孩子答题页 `http://<内网IP>:8088/`（手机视口 430×932 @2x） | 860×1864 |
| `student-info.png` | 后台「学生信息」页签 | 1280×900 |
| `learning-stats.png` | 后台「学习情况」：学情卡片 + 学习统计趋势图 + 每科正确率 | 806×712 |

## 想换成自己的截图

1. 截好图（PNG / JPG 都行，JPG 体积更小）；
2. 用同样的文件名覆盖这里的图（例如把截图命名为 `answer-page.png`）；
3. `git add docs/screenshots && git commit -m "docs: 更新截图" && git push` 即可，README 不用改。

如果改了文件名，记得把 `README.md`「截图」一节里的 `docs/screenshots/xxx.png` 一起改掉。

## 注意

- 截图前把姓名、设备 MAC、内网 IP 打码（浏览器地址栏露出 IP 也建议遮一下）；
- 「学习情况」那张建议同时带上「学习统计」趋势图和「每科正确率」条形图；
- 手机截图可以用「添加到主屏幕」后的页面，更像真实使用场景。
