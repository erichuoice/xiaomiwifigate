# 截图占位说明

README 顶部「截图」用的三张图就是这里的文件：

| 文件 | 对应界面 | 建议尺寸 |
|---|---|---|
| `answer-page.png` | 孩子答题页 `http://<内网IP>:8088/` | 手机竖屏，760×1120 左右 |
| `student-info.png` | 后台「学生信息」页 | 横屏 1280×800 左右 |
| `learning-stats.png` | 后台「学习情况」（含「学习统计」趋势图与「每科正确率」） | 横屏 1280×800 左右 |

## 怎么替换

1. 截好图（PNG / JPG 都行，JPG 体积更小）；
2. 用同样的文件名覆盖这里的占位图（例如把截图命名为 `answer-page.png`）；
3. `git add docs/screenshots && git commit -m "docs: 截图" && git push` 即可，README 不用改。

如果改了文件名，记得把 `README.md`「截图」一节里的 `docs/screenshots/xxx.png` 一起改掉。

## 小建议

- 截图前把名字、设备 MAC、内网 IP 打码（浏览器地址栏露出 IP 也建议遮一下）；
- 手机截图可以用「添加到主屏幕」后的页面，更像真实使用场景；
- 学习情况那张建议同时带上「学习统计」的柱线图和「每科正确率」条形图，最能体现功能。
